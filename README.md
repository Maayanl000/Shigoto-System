# Shigoto

Shigoto is a full-stack Applicant Tracking System for managing technology recruitment workflows.

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- React
- JavaScript
- REST API
- JMS

## Features

- Candidate registration and authentication
- Role-based access for Candidates, HR, and Interviewers
- Job application workflow
- Candidate dashboard
- HR job management
- Hiring pipeline with Kanban board
- Interview management

## Project Status

This project is currently under active development.
