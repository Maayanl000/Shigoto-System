# Shigoto

Shigoto is a full-stack Applicant Tracking System (ATS) for managing technology recruitment processes.

## Project Status

Work in progress.

## Current Technology Stack

### Backend
- Java
- Spring Boot
- JPA
- REST API
- PostgreSQL

### Frontend
- React
- JavaScript
- CSS

### Development Tools
- IntelliJ IDEA
- Cursor
- Postman
- DBeaver
